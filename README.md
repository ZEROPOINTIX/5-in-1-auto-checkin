# 自用签到小助手

魔改自 [Better-MAS-Tools](https://github.com/Lance0174/Better-MAS-Tools)，一个给自己用的米哈游社区签到小工具。

> 主要改动都是大肥鱼做的，这块我自己测试是能跑的。  
> 这是我第一个 GitHub 项目，凑合用 😄

## 魔改了什么

1. **加入皎皎角（二重螺旋社区）签到**  
   参考自 [dna-builder](https://github.com/pa001024/dna-builder)。

2. **删掉了"缩小到托盘"功能**  
   原版有 bug（详见 [Issue #3](https://github.com/Lance0174/Better-MAS-Tools/issues/3)），我反正是用不到，干脆整个删了。

3. **删掉了引导教程**  
   说实话我觉得原版设计已经够简单直白了，留着反而碍眼。

4. **改了窗口标题**  
   原来左上角是「更好的 MAS 工具包」，中间还莫名其妙换一行，看着很怪。换了个名字，至少不再断行了。

5. **签到结果加了日期显示**  
   原版只显示「今日签到成功」——但如果你半夜 11 点打开，第二天它还是显示「今日」，分不清到底签没签。  
   现在会显示具体日期，并把「xx日」高亮出来，一眼就能看出今天有没有签到。
