#自用签到小助手

魔改自https://github.com/Lance0174/Better-MAS-Tools
主要都是大肥鱼改的。测试这块我自己测试是可以的
更改内容：
1.加入了皎皎角（二重螺旋社区），模仿自https://github.com/pa001024/dna-builder
2.原mas工具包有个缩小到托盘的设计，但是有bug（详见https://github.com/Lance0174/Better-MAS-Tools/issues/3）所以我索性整个直接删除了，反正我是用不到
3.删除了引导教程，有一说一我觉得原本的设计够简单直白了
4.改了个名字。原来左上角会有个 更好的mas工具（换行）包 这很诡异你知道吗hhhhhhh总之换了个名字，至少不换行了
5.原本签到完成后会显示今日签到成功，但有的时候你可能半夜11点打开然后第二天仍然显示“今日”，总之我加了个了日期显示，并且高亮了“xx日”，这样你可以自己看出来今天签到没

其实我不怎么用github，这是我第一个项目，我得研究一下怎么用这个东西
